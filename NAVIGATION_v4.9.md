# v4.9: Walk & Talk navigation

- Added **Next phrase / 次の文章へ進む** button.
- Previous and Next work while paused. The English text, Japanese translation, phrase key, and answer area update immediately, without playing audio or unpausing the timer.
- Resuming starts the selected phrase from the beginning, using the existing Japanese/English voice and accent settings.
- While playing, Next skips the current phrase and starts the following unmastered phrase; Previous restarts the preceding phrase.
- Navigation respects mastered phrase exclusions and keeps the resume cursor at the selected phrase.
- The display-only navigation does not increment playback counts until English speech actually starts.

APK build and on-device behavior have not been verified in this environment.
